# Blinkit UI Clone

A Flutter-based mobile application for grocery shopping with an intuitive and visually appealing UI. The app showcases various product categories including bestsellers, groceries, and snacks in different grid layouts.

## Features

- Clean UI similar to Blinkit app
- Dark/Light mode toggle
- Category filtering
- Search functionality
- Bloc pattern for state management

## How to Run

1. Ensure you have Flutter SDK installed (version 3.0.0 or higher)
2. Clone this repository
3. Install dependencies:flutter pub get
4. Run: flutter run
